# SMT-Data-Challenge-2026
My submission for SportsMEDIA Technology's 2026 Data Challenge.

This summer, I participated in the SMT Data Challenge, a student analytics competition involving anonymized minor league ball- and player-tracking data. In accordance with this year's prompt, the results of my project are intended for display on a minor league scoreboard, so as to help drive fan engagement. I used [R/Python] to do my data cleaning and [analysis/modeling]. 

 

 Because the rules of the competition prohibit sharing or discussing my project before finalists are announced in October, the organizers have asked me to provide this prepared text in lieu of something more comprehensive.
